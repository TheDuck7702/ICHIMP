# ICHIMP
A macronutrient management software to help anyone trying to become more healthy, made with Prossesing 4

## Features
- Add custom foods with protein, carbs, fat, and cost values
- Preloaded preset foods (e.g., Egg, Apple, Chicken Breast)
- Organize foods by meal type: Breakfast, Lunch, Dinner, Snack
- Draw food items on the GUI
- Build a summary of total nutrients and cost
- Sort the summary using Merge Sort
- Export the summary to a CSV file

## Notes
- Merge Sort is used to sort nutrients in descending order  
- The GUI is simple and displays foods and nutrient summary clearly  
- Helpers tab contains utility methods for formatting and calculations
